Repositório dedicado ao registro prático da minha jornada de evolução em **Java**, desde a sintaxe essencial e Programação Orientada a Objetos (POO) até algoritmos de estruturas de dados e desenvolvimento de APIs com o ecossistema Spring.

---

## 📚 Roteiro de Estudos

- [x] **01. Fundamentos**: Sintaxe, variáveis, operadores primitivos e estruturas de decisão.
- [ ] **02. Orientação a Objetos (POO)**: Classes, métodos, encapsulamento, herança, polimorfismo e interfaces.
- [ ] **03. Coleções & Exceções**: Listas, Sets, Maps, tratamento de erros e exceções personalizadas.
- [ ] **04. Java Moderno**: Expressões Lambda, Streams API e manipulação de datas.
- [ ] **05. Persistência & Bancos de Dados**: JDBC, JPA e Hibernate.
- [ ] **06. Spring Framework**: Injeção de Dependências, APIs REST e Spring Boot.
